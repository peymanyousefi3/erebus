# 27.0-draft.1 - Rescue Simulation 2027 on Webots R2025a

Maintained by Peyman Yousefi. This edition integrates the 8 September 2026 draft with the customized 26.2 Match Studio supervisor.

- Live supervisor-owned battery, five-second continuous contact replacement and battery-only swamp penalties.
- Smiley victims, non-scoring 3D decoys, contact-tile map encoding and draft dimensions/reporting distance.
- Complete JavaScript model templates for R2025a, including Area 4, curved walls and hazard signs.
- Retained interactive HTML/W3D replays, event CSV, map review, HUD, Keep Files, source refresh and remote/Docker controls.
- Recovery for older retained robot models, correct no-camera/custom-camera interfaces and protection against repeated final map awards.
- Duplicate reports cannot score a neighboring sign; reporting a victim as a cognitive target or vice versa is penalized.

The matching game-info example accepts the 2027 20-byte battery reply. Existing 16-byte-only readers need updating.

The draft leaves battery calibration unspecified. This release retains the supplied motor calibration and uses an organizer-configurable swamp multiplier of five. Its explicit mapping formula is retained despite the draft's conflicting prose about the maximum multiplier.

Validation is in progress. Portable regression checks and local R2025a field, battery, sensor, connection and full-duration checks are recorded before publication. The Linux workflow also tests the official unmodified R2025a package and a real Docker controller connection. Platform results and the final test summary will be added after the complete run.
