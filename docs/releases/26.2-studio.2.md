# Erebus Match Studio 26.2 — Preview 2

Based on official RoboCupJunior Erebus 26.1. This is an independent preview maintained by Peyman Yousefi.

## Recording fix

Webots R2023b can omit initial animation node states while its X3D streaming server is enabled. This produces invalid first-frame JSON, preventing the recording ZIP and result metadata from being completed.

The exporter now restores those missing states from the original exported scene, validates the full animation and then finishes the normal replay/ZIP workflow. Later motion frames, timestamps and labels remain unchanged. Unrecognized corruption is still rejected. No world reload, robot-controller change or additional simulation step is introduced.

## Verification

- Both real failing streaming exports recovered while preserving all 151 later frames in each recording.
- A new Webots match completed with `--stream=x3d`: movement, pause/resume, robot exit, saved score/events, valid recording ZIP, map review and CSV export.
- Direct-file HTML playback, play/pause and forward/backward timeline seeking checked in Chrome on macOS.
- Portable regression coverage added for exact initial scene values, mixed missing/present entries, idempotence and corruption guards.

## Unchanged findings

The camera-parameter messages from the original robot generator are unchanged. The local Webots installation's missing Qt-filter configuration and graphics-driver diagnostics are not suppressed or patched by this release. Full Windows/Linux Webots runtime and physical-phone playback remain unverified.

## Download and start

Extract the complete release ZIP. Install `requirements.txt` with the Python interpreter configured for Webots, then run `python scripts/prepare_world.py` once before opening a supplied world in `game/worlds/`. Substitute your interpreter's command for `python` if needed. The README documents controller loading and settings.

The package excludes private controllers and recordings. Original credits and third-party notices are retained; see NOTICE.md for the upstream licensing limitation.
