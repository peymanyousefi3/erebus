# Erebus Match Studio 26.2 - preview release

Based on official RoboCupJunior Erebus `v26.1` (`a53a7965`). This is an independent fork, not an official Erebus 26.2 release.

## Added

- Automatic interactive HTML replay recording, per-match folders and ZIP packaging.
- Final score breakdown and timestamped events synchronized with playback and seeking.
- Configurable Webots HUD with score, elapsed time and the latest three events.
- Submitted-map review with cell comparisons, rotation, zoom, PNG and raw matrix export.
- Responsive supervisor panel, original-controller path refresh and Match Events CSV export.

## Fixed

- Unrelated settings changing Remote mode.
- Docker paths containing commas and duplicate Docker-start requests.
- Missing/empty controller checks, malformed JSON recovery and refresh-related file-picker replay.

## Packaging

Official worlds and examples are retained. Local controllers, logs, recordings, generated maps and cached native binaries are excluded. Original and third-party notices are retained; see NOTICE.md for the upstream licence limitation.

## Verification

Two short real Webots match cycles and direct HTML playback were checked on macOS with Chrome. Successful Docker container startup, Safari and Windows/Linux Webots runtime behavior remain unverified. The battery display is a 100% placeholder.
