# 27.0-draft.1 - Rescue Simulation 2027 on Webots R2025a

Maintained by Peyman Yousefi. This edition integrates the 8 September 2026 draft with the customized 26.2 Match Studio supervisor.

- Live supervisor-owned battery, five-second continuous contact replacement and battery-only swamp penalties.
- Smiley victims, non-scoring 3D decoys, contact-tile map encoding and draft dimensions/reporting distance.
- Complete JavaScript model templates for R2025a, including Area 4, curved walls and hazard signs.
- Retained interactive HTML/W3D replays, event CSV, map review, HUD, Keep Files, source refresh and remote/Docker controls.
- Recovery for older retained robot models, correct no-camera/custom-camera interfaces and protection against repeated final map awards.
- Duplicate reports cannot score a neighboring sign; reporting a victim as a cognitive target or vice versa is penalized.

The matching game-info example accepts the 2027 20-byte battery reply. Existing 16-byte-only readers need updating.

The draft leaves battery calibration unspecified. This release retains the supplied motor calibration and uses an organizer-configurable swamp multiplier of five. Its explicit mapping formula is retained despite the draft's conflicting prose about the maximum multiplier.

## Verified results

- **32 native R2025a cases passed:** 31 core cases in the [core run](https://github.com/peymanyousefi3/erebus/actions/runs/41730824629), followed by the corrected [real Docker connection](https://github.com/peymanyousefi3/erebus/actions/runs/41735085303). The earlier combined workflow was stopped at the Docker import failure; its 31 completed core cases all passed. These are results from separate runs, not a claim that the earlier combined workflow finished successfully.
- All 14 bundled worlds load, including the internal test world. Generated two/four-wheel, camera-free, custom-camera and complete-sensor configurations expose working devices and data.
- Contact replacement occurred after 5.008 stationary simulated seconds. Natural battery depletion reached zero at 80.544 simulated seconds under the reference motor calibration.
- The full simulation reached 480 seconds. A separate native boundary test verified the 600-second real-time cutoff. Physics and production time limits remained active.
- All 80 valid token reports across five scoring maps passed, together with map evaluation, exit/map awards and rounding checks.
- Local, IPC, TCP and Docker controller paths passed, including actual 20-byte game-info replies carrying battery percentage. Replays contain W3D scenes and valid ZIP packages.
- **17 regression scripts and the interface contract passed on macOS, Windows and Linux**, on Python 3.10 and 3.12. See the [six-platform run](https://github.com/peymanyousefi3/erebus/actions/runs/41728712476) and the latest Docker run's portable jobs.
- Rendered checks covered the supervisor at normal and 390-pixel widths, low-battery display, retained setup controls, saved cyan contact-map inspection, actual R2025a replay rendering, pause, forward/backward seeking and event synchronization.

The headless Linux checks disable the unused main view. Timing fixtures sample camera data first, then disable unused imaging; separate sensor cases keep imaging enabled. These checks establish functionality, not running-speed benchmarks.

## Scope and remaining platform checks

The complete native qualification used the official, unmodified Linux R2025a package. The local Mac run completed 19 smoke cases before the retained-model startup fault was found and corrected; a focused clean-Linux recovery check subsequently passed. The final complete native Mac rerun remains pending because Webots was left closed to preserve the user's screen setup. Native Windows Webots has not been qualified. Portable code tests on Mac and Windows are not substitutes for native simulator tests.

The release implements a draft rulebook. Administrative judging procedures remain human responsibilities. Apply the draft's organizer graphics profile in Webots preferences: Ambient Occlusion Low, Texture Quality Low, Max Texture Filtering 4, Shadows Disabled and Anti-aliasing Disabled.
